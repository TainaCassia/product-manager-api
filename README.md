# 🛍️ Product Manager API

Este projeto é uma API desenvolvida em **Node.js**, utilizando **Express.js**, **MySQL** e arquitetura organizada em pastas, com foco no gerenciamento completo de produtos, categorias, usuários e rotas de integração.

É um sistema criado como atividade da disciplina de **Programação Web II (PWII)**, permitindo realizar operações completas de CRUD (Create, Read, Update, Delete).

---

## 🚀 Tecnologias Utilizadas

- **Node.js**
- **Express.js**
- **MySQL**
- **Nodemon**
- **dotenv**
- **MVC (Model - View - Controller)**
- **EJS** (se estiver usando para views)
- **Fetch API** para o frontend
- **Git & GitHub**

---

## 📁 Estrutura de Pastas

product-manager-api/
│── controllers/ # Lógica de negócio
│── models/ # Acesso e estrutura ao banco de dados
│── routes/ # Rotas de API
│── database/ # Conexão com MySQL
│── public/ # Arquivos estáticos
│── views/ # Páginas EJS (caso utilize)
│── server.js # Inicialização da aplicação

## 📌 Funcionalidades


✔️ Cadastro de produtos 
✔️ Consulta de produtos existentes  
✔️ Rotas organizadas  
✔️ Conexão com banco MySQL  
✔️ Estrutura MVC para manter o código limpo
